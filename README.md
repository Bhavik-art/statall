# Statistics for Machine Learning and Data Science: Practical Exam

Complete, working reference for practical exams and experiments in Statistics for Machine Learning and Data Science.

## Content & Experiments
- **Experiment 2: Descriptive Statistics & EDA**
  - `experiments/q1.py`: Iris - Mean, median, standard deviation, and box plot
  - `experiments/q2.py`: Diabetes - BMI distribution, skewness, kurtosis, and histogram
- **Experiment 3: Correlation, Distance Measures & Preprocessing**
  - `experiments/q3.py`: Iris - Pearson correlation heatmap and strongest correlated feature pair
  - `experiments/q4.py`: Euclidean distance before and after standardization
- **Experiment 4: Statistical Inference & Hypothesis Testing**
  - `experiments/q5.py`: One-sample t-test (two-tailed hypothesis)
- **Experiment 5: Resampling & Confidence Intervals**
  - `experiments/q6.py`: Bootstrap 95% confidence interval for the mean
- **Experiment 6: Regression Models**
  - `experiments/q7.py`: Diabetes - Simple linear regression and residual diagnostics
  - `experiments/q8.py`: Linear vs Ridge regression comparison with MSE & R²
- **Experiment 7: Classification Models**
  - `experiments/q9.py`: Iris - Binary logistic regression decision boundary
  - `experiments/q10.py`: Iris - Decision Tree classifier and text-based tree visualization
- **Experiment 8: Clustering & Dimensionality Reduction**
  - `experiments/q11.py`: Iris - K-Means clustering and cluster centers
  - `experiments/q12.py`: Iris - PCA 2D projection and explained variance ratio
- **Experiment 9: Model Validation & Explainability**
  - `experiments/q13.py`: Breast Cancer - Logistic regression, ROC-AUC curve & confusion matrix
  - `experiments/q14.py`: Breast Cancer - Random Forest Gini feature importances
  - `experiments/q15.py`: Breast Cancer - Permutation importance on test set

## Datasets Included
- `iris.csv` (150 rows)
- `diabetes.csv` (442 rows)
- `breast_cancer.csv` (569 rows)

- `all_experiments_code.py`: Consolidated Python script with all 15 experiments.
